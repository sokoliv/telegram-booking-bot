# Telegram-бот для записи клиентов

Бот для барбершопов, салонов и частных мастеров: клиент записывается на услугу
сам, мастер получает уведомления, а двойные записи на одно время исключены.

## Возможности

- Выбор услуги, даты (7 дней вперёд) и свободного времени кнопками
- Занятое время пропадает из списка, прошедшее время сегодня не показывается
- Клиент смотрит свои записи и отменяет их командой /my
- Мастер мгновенно получает уведомления о новых записях и отменах
- Мастер смотрит список ближайших записей командой /list
- Автоматическое напоминание клиенту за 2 часа до визита
- Данные хранятся в SQLite

## Технологии

Python 3.12, aiogram 3, SQLite

## Запуск

1. Создайте бота у @BotFather и получите токен
2. Узнайте свой Telegram ID у @userinfobot
3. Скопируйте `.env.example` в `.env` и заполните значения
4. Установите зависимости и запустите:

```
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python bot.py
```

## Настройка под себя

Услуги, цены и рабочие часы меняются в начале файла `bot.py`
(словарь `SERVICES` и список `TIMES`).
